# Anticípate con IA: crea un modelo predictivo sin programar

Material del taller realizado en INMERXIA 2026 por Ana Isabel Oviedo
Carrascal, del Centro de Inteligencia Artificial y Ciencia de Datos
IA&Data UPB.

## Objetivo
Construir y evaluar un modelo predictivo de abandono de clientes
mediante KNIME Analytics Platform, sin necesidad de programar.

## Archivos
- Presentación del taller.
- Histórico de clientes para entrenamiento y evaluación.
- Clientes para realizar predicciones.

Los datos son sintéticos y se utilizan exclusivamente con fines didácticos.

## Herramienta
Instala la versión gratuita de KNIME Analytics Platform:
https://www.knime.com/downloads
